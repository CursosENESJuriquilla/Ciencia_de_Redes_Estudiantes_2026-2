# Proyecto Final de Ciencia de Redes: Redes de Ingredientes en Recetas Regionales



Este repositorio contiene el desarrollo del proyecto final de la materia de \*\*Ciencia de Redes\*\* de la licenciatura de Matemáticas para el Desarrollo ENES-J semestre 2026-2. Dicho proyecto tiene el objetivo de analizar y comparar las recetas de dos regiones: Europa Occidental y Europa del Sur.



El desarrollo del proyecto se divide en:



1\. Construcción de las redes

2\. Descripción general de los datos

3\. Propiedades básicas de las redes

4\. Centralidades

5\. Comunidades

6\. Comparación entre regiones

7\. Comparación con modelos aleatorios



Para su reproducción, es necesario contar con las librerías de pandas, networkx, itertools, collections, matplotlib.pyplot y numpy.



Los datos se obtuvieron del artículo \*Flavor network and the principles of food pairing\*.
